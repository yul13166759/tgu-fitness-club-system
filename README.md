## 📌 Описание проекта

Разработана спецификация требований (SRS) и спроектирована информационная система для управления фитнес-клубом. Система включает:
- Контроль доступа по картам с интеграцией турникета
- Бронирование групповых занятий и персональных тренировок
- Лист ожидания с автоматической записью
- Управление абонементами и картами клиентов
- Отчётность для директора и администратора

### 2. Моделирование процессов (BPMN)
- Процесс «AS IS» (текущий)
- Процесс «TO BE» (автоматизированный)
- Точки автоматизации
### 2.1. Процесс: Вход и выход клиента в зал (To-Be)

```mermaid
flowchart TD
    Start([Старт: Клиент подходит к турникету]) --> Task1[Клиент прикладывает карту]
    Task1 --> Task2[Система считывает ID карты]
    Task2 --> Task3[Система проверяет статус]
    Task3 --> Gateway{Статус абонемента?}
    Gateway -->|Active| Task4[Открыть турникет]
    Task4 --> End1([Успешный вход])
    Gateway -->|Frozen| Task5[Показать: Абонемент заморожен]
    Task5 --> End2([Вход запрещён])
    Gateway -->|Expired/Blocked| Task6[Показать причину отказа]
    Task6 --> End3([Вход запрещён])
```

### 2.2. Процесс: Бронирование занятия и лист ожидания (To-Be)**

```mermaid
flowchart TD
    Start1([Старт: Клиент открывает расписание]) --> Task1[Клиент выбирает занятие]
    Task1 --> Gateway1{Есть места?}
    Gateway1 -->|Да| Task2[Клиент бронирует]
    Task2 --> Task3[Система создаёт бронь]
    Task3 --> End1([Успешная бронь])
    Gateway1 -->|Нет| Task4[Показать кнопку Встать в лист ожидания]
    Task4 --> Task5[Клиент нажимает кнопку]
    Task5 --> Task6[Система добавляет в очередь]
    Task6 --> End2([Клиент в листе ожидания])
    
    Start2([Событие: Освободилось место]) --> Task7[Найти клиента с position=1]
    Task7 --> Gateway2{Абонемент активен?}
    Gateway2 -->|Да| Task8[Создать бронь]
    Task8 --> Task9[Отправить уведомление]
    Task9 --> End3([Успешная автозапись])
    Gateway2 -->|Нет| Task10[Пропустить клиента]
    Task10 --> Task11[Взять следующего]
    Task11 --> End4([Переход к следующему])
```

## 🎓 Ключевые результаты

### Сущности системы:
- **Клиент** (Client)
- **Карточка** (Card)
- **Абонемент** (Membership)
- **Занятие** (Class)
- **Бронь** (Booking)
- **Лист ожидания** (Waitlist)
- **Тренер** (Trainer)
- **Персональная тренировка** (PersonalTraining)

### Основные функции:
✅ Выпуск/блокировка карт доступа  
✅ Проверка активного абонемента при входе  
✅ Бронирование занятий (7 дней вперёд)  
✅ Отмена брони (не позднее чем за 2 часа)  
✅ Автоматическая запись из листа ожидания  
✅ Фиксация входа/выхода через турникет  
✅ Уведомления (push/SMS/email)  
✅ Отчётность по выручке и загруженности залов
